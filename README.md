# aftergrow

Aftergrow's Pinterest, automated.

- `RUNBOOK.md`: what the Monday and Thursday autopilot does, the reload rules, the board evidence and the fact sheet.
- `status.json`: the current mode (`live` or `blocked`).
- `queue.json` / `queue.csv`: every pin and its status.
- `pins/`: the finished images (public, so Tailwind can fetch them).
- `engine/`: the pin engine and the queue tools.
